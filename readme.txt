Choose a difficulty level (Easy / Medium / Hard) for the WordPress Site Editor.

== Description ==

When you open the Site Editor, Game Mode prompts you to choose a difficulty:

* **Easy** — patterns are content-only, distraction-free is on, only color and font size are exposed in the inspector, theme blocks are hidden.
* **Medium** — patterns are content-only, default block-support controls, theme blocks available.
* **Hard** — every block-support control is expanded by default, no content-only locks, full editor.

A persistent switcher in the bottom-right of the editor lets you change levels at any time.
