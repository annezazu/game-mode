Choose a difficulty level (Simple / Intermediate / Advanced) for the WordPress Site Editor.

== Description ==

When you open the Site Editor, Game Mode prompts you to choose a difficulty:

* **Simple** — patterns are content-only, focus mode is on, only color and font size are exposed in the inspector, theme blocks are hidden, the inserter is patterns-only.
* **Intermediate** — patterns are content-only, default block-support controls, theme blocks available, full inserter.
* **Advanced** — every block-support control is expanded by default, no content-only locks, full editor.

A persistent switcher in the bottom-right of the editor lets you change levels at any time.
